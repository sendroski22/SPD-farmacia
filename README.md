# Pastillero semanal (SPD)

Recurso interactivo para el CFGM Farmacia y Parafarmacia · Módulo *Dispensación de productos farmacéuticos* · RA2, CE j): "Se ha realizado el servicio personalizado de dosificación".

5 casos clínicos de dificultad creciente. El alumnado arrastra pastillas a un pastillero semanal (7 días x 4 tomas) y autocorrige con nota sobre 10 (todo o nada por casilla).

## Publicar en GitHub Pages
Sube `index.html` y `LICENSE` al repositorio y activa *Settings > Pages > Deploy from a branch > main / root*.
